# ResolveAI – Customer Support Resolution Assistant

TRACK_ID=PS04

## Overview

ResolveAI is an AI-powered customer support assistant for telecom companies.

The system helps customer support teams resolve customer issues faster by:
- Understanding customer queries
- Retrieving relevant support articles
- Generating AI-powered responses
- Asking follow-up questions when needed
- Escalating complex cases to human agents

## Features

- AI-powered support assistant
- Retrieval-Augmented Generation (RAG)
- Knowledge base search using FAISS
- Gemini 2.5 Flash integration
- Customer profile analysis
- Confidence scoring
- Human agent escalation
- Modern web dashboard

## Technology Stack

- Python
- FastAPI
- Gemini 2.5 Flash
- Gemini Embeddings
- FAISS
- HTML
- CSS
- JavaScript

## How It Works

Customer Query
→ Retrieve Relevant Articles
→ AI Analysis
→ Generate Response
→ Confidence Check
→ Resolution or Escalation

## Installation

1. Clone the repository

```bash
git clone https://github.com/Apurva-hash/customer-support-resolution-assistant.git
```

2. Install dependencies

```bash
pip install -r requirements.txt
```

3. Run the application

```bash
python app.py
```

4. Open in browser

```text
http://localhost:8000
```
